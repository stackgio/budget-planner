# budget-planner

- **[`moneyflow/`](moneyflow/README.md)** — MoneyFlow, a personal finance dashboard built around biweekly paychecks (Next.js + Prisma). Start with `cd moneyflow && npm install && cp .env.example .env && npm run setup && npm run dev`.
- **[`debt-challenge/`](debt-challenge/index.html)** — Stack With Gio $4,000 Debt Payoff Challenge: a self-contained, mobile-first tile tracker. Open `debt-challenge/index.html` in a browser (no install or build).
- **`video/`** — Stack With Gio Remotion video projects.
