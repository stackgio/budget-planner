# budget-planner

A one-page 70/20/10 budget (Needs / Investing / Fun) with a monthly breakdown and a biweekly paycheck system.

- Edit any amount on the page; totals, leftovers and paycheck splits recalculate live.
- Edits and checklist ticks are saved in your browser (localStorage).
- Light and dark themes in a Netlify-style teal palette.

## Deploy to Netlify

No build step. Either:

1. **Drag & drop:** go to https://app.netlify.com/drop and drop this folder, or
2. **From Git:** Netlify → Add new site → Import from GitHub → pick this repo. Leave the build command empty; publish directory is `.` (already set in `netlify.toml`).
