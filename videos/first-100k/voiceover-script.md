# Voiceover script — "Your first $100,000" v2 (about 26 s)

Paste the text into ElevenLabs as one take, in the same voice as the original
(its file name suggests speed 1.00, stability 50, similarity 75).
Numbers are written out so the voice reads them correctly.

```
Your first hundred thousand could take about twenty-six years… or about six and a half.

Starting from zero, assuming eight percent annual growth:

Invest a hundred dollars a month — about twenty-six years.

Two hundred fifty — about sixteen years.

Five hundred — about eleven years.

A thousand — about six and a half years.

Returns aren't guaranteed, but your monthly contribution makes a big difference.

Which amount could you realistically invest every month?
```
